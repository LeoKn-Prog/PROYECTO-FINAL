# Simulador de Compras Familiares

## Descripción

Este proyecto fue desarrollado para la materia de Programación Web I.

La aplicación permite simular compras familiares mediante el registro de productos, cálculo de gastos y análisis del presupuesto disponible. El objetivo es ayudar a determinar si una compra puede realizarse dentro de un presupuesto establecido y mostrar una interpretación de los resultados obtenidos.

## Problema Abordado

Muchas familias necesitan administrar adecuadamente sus recursos económicos para cubrir gastos de alimentación y productos esenciales. Una mala planificación puede provocar que el presupuesto disponible sea insuficiente.

Este simulador permite visualizar el impacto de las compras realizadas y analizar el nivel de gasto de forma sencilla.

## Tecnologías Utilizadas

* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Registro de productos.
* Cálculo automático del costo total.
* Comparación con el presupuesto familiar.
* Clasificación del nivel de gasto.
* Interpretación de resultados.
* Barra visual de uso del presupuesto.
* Casos de estudio predefinidos.
* Diseño responsivo para distintos dispositivos.
